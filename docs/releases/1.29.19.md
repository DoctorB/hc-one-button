# HCOneButton v1.29.19

## Find HCOneButton at a glance.

> **The AddOns list now shows the HCOneButton icon instead of a question mark.**

Version `1.29.19` gives HCOneButton its own icon in the AddOns list at character selection: the red "1" medallion from the project logo.

## New — AddOns list icon

- The add-on declares its icon in the TOC, so the AddOns list shows the HCOneButton medallion next to its name.
- The icon is packaged with the add-on; no extra download is needed.

**Example:** open **AddOns** at character selection and HCOneButton is easy to spot by its red "1" medallion.

## Upgrade and safety

- **No reset required.** Settings, action slots, permanent bindings, combat history and learned adjustments are preserved.
- Gameplay is unchanged: the Advisor, BASE, the Action Panel and every class policy behave as in `1.29.18`, including the Hunter Auto Shot range fix.
- After updating, restart the game client: the AddOns list reads the icon at startup.

## Validation and limitations

- **57 Lua files**, **44 Lua regression suites**, **58 TOC references** and **20 offline release-tool tests** pass; the addon package contains **63 files**.
- The TOC manifest regression checks the icon file (64x64, 32-bit TGA) and the release tooling refuses to build a package without it.

- World of Warcraft Classic Era / Hardcore — Interface `11509`
